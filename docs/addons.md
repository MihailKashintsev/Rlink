# Дополнения Rlink

Дополнение — это отдельный экран внутри мессенджера, который пользуется теми же
возможностями, что и встроенные функции: каталог, воспроизведение, локальное
хранилище, расшифровка речи. Встроенная **«Музыка»** сделана ровно так и служит
образцом: она не имеет ни одной привилегии, недоступной стороннему дополнению.

Найти установленные дополнения: **⋯ → Дополнения** (рядом с «Ботами»), а также
через глобальный поиск — дополнения ищутся по названию, описанию и ключевым
словам.

---

## Сразу о главном: Python или нет

Часто просят «дополнения на Python, как в Telegram». Здесь два разных понятия,
и их стоит развести:

- В Telegram **mini-apps — это веб-приложения (HTML/JS)** в webview. Python там
  живёт только на стороне бота, на сервере.
- Запустить Python **внутри клиента** нельзя без тяжёлого рантайма: на вебе это
  Pyodide (~10 МБ wasm, только веб), на мобильных — встроенный CPython, который
  заметно раздувает сборку.

Поэтому в Rlink три честных пути, и у каждого своя ниша:

| Путь | Язык | Где выполняется | Когда подходит |
|---|---|---|---|
| **Боты** (уже работают) | Python | На машине пользователя или на релее | Логика, интеграции, реакция на сообщения |
| **Встроенные дополнения** (этот документ) | Dart/Flutter | В приложении | Свой экран и интерфейс внутри мессенджера |
| Mini-apps (планируется) | HTML/JS | Webview внутри приложения | Готовые веб-приложения без пересборки клиента |

Если нужна **логика** — пишите бота на Python. Если нужен **экран** — дополнение.

## Из чего состоит дополнение

Дополнение описывается записью `AddonInfo` (`lib/services/addons_registry.dart`):

```dart
AddonInfo(
  id: 'ваш.идентификатор',      // уникальный, в стиле обратного домена
  title: 'Название',
  subtitle: 'Короткое описание — видно в списке и в поиске',
  icon: Icons.extension_outlined,
  color: Color(0xFF00BCD4),
  keywords: ['слова', 'для', 'поиска'],
  open: () => const ВашЭкран(),  // обычный Flutter-виджет
)
```

Всё, что нужно от экрана — быть обычным виджетом. Никакой особой базовой
структуры наследовать не требуется.

## Что дополнение может использовать

Это те же сервисы, на которых построена «Музыка»:

**Воспроизведение — `VoiceService`**

```dart
VoiceService.instance.play(url, title: 'Название');   // один трек
VoiceService.instance.playQueue([...]);               // очередь с автопереходом
VoiceService.instance.pausePlayback();
VoiceService.instance.resumePlayback();
VoiceService.instance.seekTo(0.5);                    // 0..1
```

Реактивное состояние: `playbackSession`, `playProgress`, `playDuration` —
обычные `ValueNotifier`, подписывайтесь через `ValueListenableBuilder`.

Важное свойство: воспроизведение живёт в сервисе, а не в экране. Пользователь
уходит из дополнения — трек продолжает играть и появляется в общем мини-плеере.
Ничего для этого делать не нужно.

**Каталог музыки — `MusicCatalogService`**

```dart
await MusicCatalogService.instance.search('запрос');       // поиск
await MusicCatalogService.instance.randomStream(page: 0);  // случайный поток
```

**Локальное хранилище**

`SharedPreferences` — как в `MusicLibraryService`. Ничего не уходит на сервер.

**Расшифровка речи — `WhisperWebService`** (веб)

```dart
await WhisperWebService.instance.init();
final text = await WhisperWebService.instance.transcribe(url);
final segments = await WhisperWebService.instance.transcribeSegments(url);
```

`transcribeSegments` возвращает отрезки с таймкодами — на этом сделана панель
«Текст (бета)».

## Как добавить своё дополнение

1. Создайте экран, например `lib/ui/screens/my_addon_screen.dart`.
2. Добавьте запись в список `addons()` в `lib/services/addons_registry.dart`.
3. Пересоберите приложение.

Дополнение сразу появится в списке **⋯ → Дополнения** и в глобальном поиске —
отдельно регистрировать его в поиске не нужно.

## Ограничения, о которых стоит знать заранее

- **Пересборка обязательна.** Сейчас дополнения компилируются вместе с
  приложением: загрузки чужого кода на лету нет. Это сознательно — исполнение
  произвольного кода в мессенджере с E2E-шифрованием требует песочницы,
  которой пока нет.
- **Изоляции между дополнениями нет.** Пока все они — часть приложения и имеют
  те же права. Не добавляйте код, которому не доверяете.
- **Каталог музыки — инди.** Audius, без ключа и регистрации. Мировой популярной
  музыки там нет: бесплатно и легально стримить лейблы по ссылке невозможно.
- **Расшифровка песен — бета.** Whisper обучен на речи, а не на пении под
  музыку; на песнях он ошибается заметно чаще, чем на голосовых сообщениях.

## Что планируется

- Загрузка дополнений без пересборки (mini-apps в webview).
- Песочница и права: дополнение просит доступ, пользователь подтверждает.
- Единый API для доступа к чатам и контактам — сейчас его сознательно нет.
