Как скачать Rlink

Выбери свою платформу — пошаговая инструкция по установке займёт меньше минуты.

Актуальная версия: …
1
Скачай APK-файл
Нажми кнопку ниже — файл Rlink-….apk начнёт скачиваться на твой Android.
Скачать Rlink для Android
2
Разреши установку из неизвестных источников
Android по умолчанию блокирует установку APK не из Play Store. Когда появится предупреждение — нажми «Настройки» и включи «Разрешить установку» для браузера или файлового менеджера.
На MIUI (Xiaomi): Настройки → Конфиденциальность → Установка неизвестных приложений
3
Открой скачанный файл
Перейди в папку Загрузки и нажми на файл Rlink-….apk. Подтверди установку.
Приложение занимает около 150 МБ. Установка займёт несколько секунд.
4
Включи Bluetooth и запускай
Открой Rlink, разреши доступ к Bluetooth и геолокации (нужно для BLE). Готово — найди кого-то поблизости и начни общаться!
Дальше приложение обновляется само: когда выйдет новая версия, Rlink предложит обновиться в один тап.
1
Скачай архив для macOS
Подходит только для Mac с чипом Apple Silicon (M1, M2, M3). Intel Mac пока не поддерживается.
Скачать Rlink для macOS
2
Распакуй архив
Дважды кликни на скачанный Rlink-…_macos.zip — он распакуется автоматически. Перетащи приложение Rlink.app в папку Программы (Applications).
3
Обойди Gatekeeper
При первом запуске macOS покажет предупреждение «Приложение не может быть открыто». Это нормально для неподписанных приложений.
Кликни правой кнопкой на Rlink.app → «Открыть» → «Открыть» ещё раз в диалоге. После первого раза предупреждение больше не появится.
sudo xattr -cr /Applications/Rlink.app
Или запусти команду выше в Терминале, если правый клик не помогает.
4
Разреши Bluetooth
При первом запуске macOS запросит доступ к Bluetooth — нажми «Разрешить». Готово!
1
Скачай архив для Windows
Портативная сборка для Windows 10/11 (x64). Устанавливать ничего не нужно — просто распакуй и запусти.
Скачать Rlink для Windows
2
Распакуй архив
Кликни правой кнопкой на Rlink-…_windows.zip → «Извлечь всё». Помести папку в удобное место (например, в Документы).
3
Запусти Rlink.exe
Открой распакованную папку и запусти rlink.exe. Windows SmartScreen может показать предупреждение — это нормально для приложений без подписи.
Если появится «Система Windows защитила ваш компьютер» — нажми «Подробнее» → «Выполнить в любом случае».
4
Включи Bluetooth и запускай
Убедись, что на ПК включён Bluetooth, и начинай общаться с теми, кто рядом.
Обновления встроены: новая версия скачается и заменит приложение сама, по кнопке.
1
Linux — скоро
Версия для Linux (.AppImage и .deb) находится в разработке.

Частые вопросы
Нужен ли интернет для работы Rlink?
Нет. Rlink работает полностью без интернета — через Bluetooth Low Energy и WiFi Direct. Сервера нет, всё P2P.
На каком расстоянии работает связь?
Bluetooth Low Energy — до 30 метров, WiFi Direct — до 100+ метров. При наличии нескольких устройств сообщения передаются транзитом через mesh-сеть (до 7 промежуточных узлов).
Безопасны ли мои сообщения?
Да. Rlink использует сквозное шифрование E2EE с эфемерными ключами X25519 и шифрованием ChaCha20-Poly1305. Никакие данные не проходят через сервер.
Нужна ли регистрация или номер телефона?
Нет. Rlink не требует ни регистрации, ни аккаунта, ни номера телефона. Просто установи и пользуйся.
Почему Android предупреждает об установке?
Rlink распространяется как APK-файл напрямую, минуя Play Store. Android предупреждает обо всех таких приложениях. Это нормально — просто разреши установку из неизвестных источников в настройках.
Приложение бесплатное?
Да, полностью бесплатно. Нет рекламы, нет подписки, нет скрытых платежей.
