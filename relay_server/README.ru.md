# rlink-relay

**[English](README.md) | Русский**

Relay-сервер для [Rlink](https://github.com/MihailKashintsev/Rlink) — гибридного mesh+relay мессенджера. Небольшой Dart WebSocket-сервер с минимумом зависимостей: маршрутизирует end-to-end зашифрованные пакеты между клиентами по публичному ключу, держит офлайн-почтовый ящик для получателей не в сети и опционально пересылает web push-уведомления. Он никогда не видит текст сообщений и никогда не хранит приватный ключ; при полной компрометации этого сервера максимум, что можно слить — метаданные (кто онлайн, размеры/тайминг пакетов), а не содержимое переписки.

Это по-настоящему zero-knowledge relay, а не маркетинговое заявление: прочитайте [`bin/server.dart`](bin/server.dart) — там нет ни одного пути кода, который расшифровывает сообщение между клиентами.

## Что он делает

- **Маршрутизация сообщений**: адресная доставка по публичному ключу или широковещательная рассылка для presence-подобных пакетов — повторяет модель пакетов клиентского `GossipRouter` (см. основной [репозиторий Rlink](https://github.com/MihailKashintsev/Rlink)).
- **Офлайн-почтовый ящик**: складывает пакеты для получателя, который сейчас не подключён, и воспроизводит их при переподключении.
- **Presence**: статус онлайн/отошёл между контактами.
- **Web push**: push на основе VAPID для web-клиента, когда вкладка закрыта.
- **Бэкенд админ-панели**: защищённая паролем встроенная в приложение админ-панель (доступна через 16 тапов по экрану «О проекте»), охраняется переменной `RELAY_ADMIN_HASH`.
- **Опциональные, отделимые функции** — ни одна из функций выше от них не зависит: OAuth-бэкенд Google Drive (постоянная привязка Drive для бэкапов каналов), Rlink Premium через ЮKassa, каталог ботов.

## Как поднять свой

Смотрите **[SELF_HOSTING.md](SELF_HOSTING.md)** — путь на 5 минут: `docker compose up`, указать адрес в настройке приложения «Свой relay-сервер». Свой relay даёт сообщения, presence и офлайн-очередь — звонки/TURN, платежи Premium, перевод и музыкальный каталог осознанно остаются привязаны к официальному серверу (self-host-версии незачем их переизобретать).

Про TURN-развёртывание именно этого проекта (не общий self-host) — смотрите [README_TURN.md](README_TURN.md).

## Разработка

```bash
dart pub get
dart run bin/server.dart
```

Настройки читаются из переменных окружения — скопируйте `.env.example` в `.env` и заполните нужное; всё, кроме `RELAY_ADMIN_HASH`, опционально (без него сервер работает как чистый транспорт сообщений).
